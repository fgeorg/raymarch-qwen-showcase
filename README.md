# Raymarch — a Qwen-vibecoded raytracer showcase

A showcase of a raymarcher / raytracer built entirely through vibecoding with a local **Qwen 3.8** LLM.

The whole point of this project: no hand-written core. Prompts in, working renderer out. It doubles as a live experiment in how far a local model gets you on GPU-adjacent, math-heavy code — SDFs, sphere tracing, shading, the works.

## Status

🚧 In progress — see [docs/](docs/) for the session log and prompt history as the project develops.

## What's coming

- A software raymarcher (SDF-based) with sphere tracing
- Procedural scenes (torus knots, terrain, fractals)
- Soft shadows, ambient occlusion, and other raytracer toys
- A record of the vibecoding process: what worked, what the model struggled with, what got fixed by prompting vs. by hand
